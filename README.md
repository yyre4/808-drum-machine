# 808 Drum Machine

A fully synthesized TR-808 style drum machine that runs in your browser. No samples — every sound is made live with Web Audio, from the original 808 circuit recipes.

## Voices

- **BD** — pitch-swept sine kick
- **SD** — noise + body snare
- **LT / MT / HT** — toms, with conga variants
- **RS** — rimshot
- **CP** — three-burst clap, with maracas variant
- **CB** — twin-oscillator cowbell (562 / 845 Hz)
- **CY / OH / CH** — cymbal and hats, built from the shared six-oscillator metallic cluster

## Features

- 16-step sequencer with per-step accents
- Per-voice Tune, Decay, Tone, and level
- Tempo and swing controls
- Five preset patterns: Boogie Nights, Four Floor, Boom Bap, Electro Funk, Acid Rain
- Clear, Randomize, and Humanize
- Trigger pads and keyboard triggering (1–9, 0, -, Space)
- Master Drive and Glue
- Tape recorder — save takes as downloadable audio files
- Dark modular panel UI

## How to use

Open `index.html` in a browser, press Play, and tap steps in the sequencer to build a pattern. Click a voice to edit its Tune, Decay, Tone, and level. No build step, no install, no account needed to play it.
